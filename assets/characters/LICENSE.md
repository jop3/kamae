`mannequin.glb` is generated by `tools/generate_mannequin.py` from the MakeHuman base mesh and the
MakeHuman "mixamo" skeleton definition shipped with MPFB 2.0.17 (MakeHuman Plugin For Blender).

- The MakeHuman base mesh, targets, rig definitions and weights are released by the MakeHuman
  community under **CC0 1.0 Universal** (public domain dedication). Output produced from them is
  therefore free to redistribute, including in this public repository.
- MPFB itself (the Blender extension code) is GPL-3.0-or-later. It is a build-time tool only; no MPFB
  code is included in this repository or in the generated asset.
- Bones have been renamed to Godot's `SkeletonProfileHumanoid` names (Hips, Spine, Chest, UpperChest,
  Neck, Head, Left/Right Shoulder, UpperArm, LowerArm, Hand, ThumbMetacarpal/Proximal/Distal,
  Index/Middle/Ring/Little Proximal/Intermediate/Distal, UpperLeg, LowerLeg, Foot, Toes). 52 bones.
